# VerbScope — аналізатор дієслів української мови

Навчальний програмний продукт для лабораторної роботи (варіант 14):
**виділення всіх дієслів** із додатковим визначенням часу, числа та роду
(для форм минулого часу).

## Можливості

- приймає український текст у графічному вебінтерфейсі;
- знаходить слова, які українська модель Stanza класифікує як `VERB` або `AUX`;
- показує початкову форму (лему);
- виводить час, число та рід для минулого часу, якщо ці ознаки наявні в морфологічному аналізі;
- підсвічує знайдені форми у введеному тексті;
- містить три тестові тексти в `tests/texts/`.

## Технології

- Python 3.10+
- Stanza — токенізація та морфологічний аналіз української мови
- Gradio — графічний вебінтерфейс
- pytest — автоматизовані тести

## Запуск на macOS

1. Розпакуйте архів і відкрийте папку `VerbScope` у VS Code.
2. Відкрийте Terminal → New Terminal.
3. Переконайтеся, що встановлено `uv`. Якщо ні, встановіть його за офіційною інструкцією: https://docs.astral.sh/uv/
4. У терміналі виконайте:

```bash
uv sync
```

5. Завантажте модель української мови (потрібен інтернет; зазвичай це робиться один раз):

```bash
uv run python -c "import stanza; stanza.download('uk')"
```

6. Запустіть застосунок:

```bash
uv run python main.py
```

7. Відкрийте адресу, яку покаже термінал (зазвичай `http://127.0.0.1:7860`).

## Тестування

```bash
uv sync --extra dev
uv run pytest
```

Перший запуск тестів також потребує завантаженої української моделі Stanza.

## Як працює алгоритм

1. Користувач вводить текст.
2. Stanza розбиває текст на речення та слова.
3. Для кожного слова модель визначає частину мови (`UPOS`) і морфологічні ознаки.
4. Слова з міткою `VERB` або `AUX` додаються до результатів.
5. Ознаки `Tense`, `Number` і `Gender` перетворюються на українські назви.
6. Результати показуються в таблиці, а знайдені словоформи підсвічуються.

## Важливі обмеження

Морфологічний аналіз виконується автоматичною статистичною моделлю, тому можливі помилки на неоднозначних словах, власних назвах, розмовних формах і текстах із друкарськими помилками. Для інфінітивів та дієслівних форм, у яких модель не визначає час, число або рід, програма показує «не визначено». Рід виводиться лише для минулого часу. Це не повноцінний синтаксичний аналіз контексту.

Перед демонстрацією перевірте результати на всіх трьох тестових текстах.
